# Contributing to NJA TACK

Report TACK-specific problems at <https://github.com/NjamesZ/nja-tack-fm1>,
not as upstream Felucca support obligations. Include candidate/version identity,
reproduction steps, routing/scale/style, expected versus observed result and
whether it was a host or actual hardware test. Never post credentials/private data.

Keep patches focused, retain licences, add failing regressions for real behavior,
and distinguish pre-existing failures from introduced ones. Run the documented
host tests and controlled hardware checks when separately authorized; do not call
an incomplete suite green. New application code uses GPL-3.0-only SPDX headers.
Engine sources retain MIT; see firmware/engines/LICENSE. Contributing means you
have the right to submit under the applicable licence. No guaranteed support.
